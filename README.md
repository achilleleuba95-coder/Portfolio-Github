# 🌌 Cosmos — Notre Système Solaire

Site web présentant les 9 astres du système solaire avec une 
mise en page timeline interactive.

[Voir le site en ligne](https://achilleleuba95-coder.github.io/Portfolio-Github/)

---

## 🛠️ Technologies utilisées

- **HTML5** — structure sémantique
- **CSS3** — mise en page et animations
- **Flexbox** — alignement et alternance gauche/droite
- **CSS Grid** — cartes de statistiques
- **Google Fonts** — typographie (Cinzel)

---

## ✨ Fonctionnalités

- Timeline verticale avec alternance gauche/droite
- Images circulaires avec effet glow propre à chaque planète
- Hover animé sur chaque planète
- Cartes de statistiques (diamètre, distance, période orbitale...)
- Navigation fixe avec scroll fluide
- Page d'accueil pleine hauteur (100vh)
- Fond étoilé en CSS pur

---

## 📚 Ce que j'ai appris

Ce projet est mon premier site personnel, réalisé dans le cadre 
de ma formation développeur web sur OpenClassrooms.

Concepts CSS maîtrisés :
- `position: fixed` et `position: absolute`
- `::before` pour la ligne verticale
- `:nth-child(even)` pour l'alternance automatique
- `box-shadow` pour les effets lumineux
- `transition` et `transform` pour les animations
- `radial-gradient` pour les étoiles et le halo
